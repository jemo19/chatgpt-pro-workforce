        Workforce controls

        Copy an intent into the Codex chat window. Commands use this page’s current safe run ID when one is needed. Natural-language equivalents also work.

        Copy-only controls. These buttons place text on your clipboard. They never execute a command, change run state, contact a worker, or keep Codex running.

        Start & observe

        Guided kickoff and read-only status views.

        • $chatgpt-pro-workforce

          Open the step-by-step setup or start a new scoped task.

          Guided · no automatic launch
        • $chatgpt-pro-workforce status RUN_ID

          Show the compact five-bar card from durable state.

          Read only
        • $chatgpt-pro-workforce tell me more RUN_ID

          Show lanes, evidence, readiness, blockers, artifacts, and next actions. status more is an alias.

          Read only

        Pause, resume & stop

        Checkpoint or reconcile work without blind retries.

        • $chatgpt-pro-workforce pause RUN_ID

          Checkpoint orchestration without routinely interrupting a healthy worker.

          Soft checkpoint
        • $chatgpt-pro-workforce resume RUN_ID

          Reload durable state, recheck controls, and reconcile duplicates or unknown outcomes.

          Reconciles before action
        • $chatgpt-pro-workforce continue RUN_ID

          Resume if paused; otherwise continue the existing bounded lane without duplicating it.

          May continue work
        • $chatgpt-pro-workforce stop RUN_ID

          Request an explicit terminal stop and durable final state; this is not the same as pause.

          Terminal · confirmation may apply

        Scope & allocation

        Review discoveries or change who handles future work.

        • $chatgpt-pro-workforce review discovered topics RUN_ID

          Review first-pass topic/category proposals before adding work.

          Decision packet
        • $chatgpt-pro-workforce change allocation RUN_ID

          Choose Pro-heavy, balanced, Codex-heavy, or local-only. Changes apply to future work and preserve active lane ownership.

          Configuration choice
        • $chatgpt-pro-workforce change concurrency RUN_ID

          Change the finite maximum for future Pro launches. Two is the safe default. More than two is high risk: likely throttling and interrupted, closed, disconnected, or inaccessible chats can cause unsaved or unverified work to be lost. It requires an explicit current-run, exact-limit acknowledgment and never closes active chats.

          High-risk above 2 · copy only

        Dashboard & help

        Manage this local view or open the complete chat help.

        • $chatgpt-pro-workforce dashboard RUN_ID

          Create or refresh the authorized loopback view and show a link only after health succeeds.

          Local files/process only
        • $chatgpt-pro-workforce dashboard stop RUN_ID

          Stop only the verified managed dashboard process; durable run state remains intact.

          Local process only
        • $chatgpt-pro-workforce uninstall

          Open a guided exact-target inventory, recoverable backup, and confirmation flow. Research data and shared control tools stay untouched.

          Destructive only after confirmation
        • $chatgpt-pro-workforce help

          Show full chat help. Topics include status, dashboard, modes, allocation, concurrency, resume, controls, prerequisites, install, and uninstall.

          Read only
